# 構成計画: 社内ヘルプデスクへの生成AIチャットボット導入検討（サンプル）

- 目的: 情報システム部長に、生成AIチャットボットの段階導入（PoC 着手）を承認してもらう
- 読み手: 情報システム部長、経営企画部（予算担当）
- 結論: 問い合わせの約6割は定型で、一次回答と記録が工数の58%を占める。SaaS型チャットボットを段階導入すれば年間約1,700万円の工数を削減でき、2年目に投資を回収できる。そこで、2027年1月のPoC着手（予算320万円）を承認いただきたい
- 素材: なし。サンプルのため数値はすべて架空とし、数値のあるスライドの source に「架空データ」と明記する
- 枚数: 16枚 / 作成: 情報システム部 企画グループ / 2026年10月
- 試算の前提（全スライド共通）: 時間単価5,000円、1件あたり対応15分、自動解決率45%、削減工数3,400h/年、5年間の総投資 約3,100万円（PoC 320万円＋本番構築 580万円＋月額40万円）
